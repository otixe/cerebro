# Security policy

## Reporting a vulnerability

Please use [Report a vulnerability](https://github.com/otixe/cerebro/security/advisories/new) (GitHub Security Advisories) so the report stays private.

If you cannot use GitHub Security Advisories, email **otixecv@gmail.com** with the subject `SECURITY: cerebro`. Please do not open a public issue for vulnerabilities.

You can expect an acknowledgement within a few days. This is a personal open-source project maintained on a best-effort basis.
